# VPNDesk 0.4.0-audit — проверенное состояние исходного архива

- Архив содержит 32 элемента, включая каталоги.
- Стек: Python 3.11+, PySide6, SQLite, keyring, psutil; sing-box — внешний компонент.
- Точка входа: `main.py`; основной GUI: `vpn_desk/window.py`; тесты: шесть файлов в `tests/`.
- `python -m compileall -q .`: успешно.
- `python -m unittest discover -s tests -v`: 31 тест пройден.
- Тесты запускались в текущей Linux-среде. Они не подтверждают запуск Qt GUI, сборку EXE или работу сетевых проверок на Windows.

## Ограничения исходного аудита
- Нет подтверждённого запуска PySide6 GUI в Windows 10/11.
- Не проверены DPI, системный трей и Windows shutdown.
- Не собран и не проверен Windows EXE.
- Не выполнен живой сетевой прогон sing-box против действующих серверов.
- Некоторые нестандартные транспорты и плагины не поддерживаются.
- Восстановление БД через UI, обновление самой VPNDesk и часть фоновой/многозадачной автоматизации не завершены.

Это не означает, что все требования ТЗ реализованы. Сверяйся с исходным кодом и полным ТЗ.
