# VPNDesk 0.4.0-audit — расширенная сборка для проверки на Windows

VPNDesk — нативное настольное приложение для каталога, импорта, организации и проверки конфигураций. Быстрый режим проверяет TCP, а полный запускает временный sing-box и проверяет сетевой ответ через конфигурацию. **Приложение не создаёт системный TUN/VPN-туннель и не меняет маршруты или DNS Windows.**

> Это расширенная аудит-сборка исходного проекта. Она прошла автоматические тесты непользовательского слоя, но её интерфейс и EXE ещё нужно проверить на реальной Windows 10/11. Не считайте её подтверждённым production-релизом до такого теста.

## Уже реализовано в этой сборке

- PySide6 GUI на русском языке, тёмная/светлая темы; все разделы прокручиваются вертикально.
- Первый запуск: базовая диагностика характеристик ПК и выбор лёгкого, среднего или интенсивного профиля нагрузки. Интенсивный профиль ограничен по ресурсам и намеренно не вызывает зависания.
- Таблицы источников и конфигураций поддерживают множественный выбор, «Выбрать все» и «Снять выбор».
- Предварительный тест URL-источников в песочнице до импорта: неудачные URL можно исключить, найденные конфигурации добавляются к каталогу.
- Главная панель со статистикой каталога, диаграммой результатов последней проверки, точками задержки и кнопками запуска/паузы/остановки проверки.
- Каталог конфигураций VLESS, VMess, Trojan, Shadowsocks, Hysteria2/Hy2 и TUIC.
- Импорт TXT, JSON, YAML/YML, CSV, CONF, LIST и ZIP; чтение больших файлов потоками; предпросмотр перед подтверждением.
- ZIP-ограничения: лимит количества записей, размера распаковки и коэффициента сжатия; вложенные ZIP не распаковываются автоматически.
- Атомарный импорт в SQLite: при ошибке вся транзакция откатывается. Создаётся резервная копия перед изменением.
- Источники: добавление, редактирование, отключение, удаление, ручная проверка, возврат из карантина.
- Карта происхождения: видно, какие конфигурации пришли из каких источников. Одна конфигурация может иметь несколько источников.
- Мягкий рейтинг источника: история успешности получения источника, свежесть проверок, доля доступных конфигураций, медианная задержка и размер выборки. Небольшая выборка и единичные сбои сглаживаются.
- История проверок конфигураций, сглаженная стабильность и рейтинг качества для сортировки.
- Быстрая TCP-проверка и отдельная полная проверка через sing-box для поддерживаемых форматов URI. Полная проверка запускает отдельный локальный SOCKS-процесс, делает HTTPS-запрос через конфигурацию и завершает процесс; системные маршруты/TUN/DNS не меняются.
- Ограниченная очередь TCP-проверки: не создаёт сразу десятки тысяч Future, поддерживает паузу, отмену и сохранение уже полученных результатов.
- Энергосбережение: лимит записей делится между активными источниками; неиспользованные места переходят источникам с более высоким рейтингом; сокращается таймаут и параллельность.
- Центр качества данных, песочница импорта, журнал событий, умная очистка старых недоступных записей с предпросмотром и резервной копией.
- Экран производительности, самодиагностика SQLite и профиля устройства; при изменении CPU/RAM пересчитывается рекомендуемая нагрузка, если включена автонастройка.
- Портативный режим: данные копируются рядом с программой в `data`; переключение требует перезапуска и не перезаписывает существующую базу.
- Плановое обслуживание: резервная копия и проверка целостности базы.
- Опциональное автовыключение Windows: после заданного времени выполняется последняя проверка; затем приложение отдельно спрашивает подтверждение и планирует выключение через 60 секунд. Есть кнопка отмены.
- Менеджер компонентов: поиск последнего стабильного sing-box в официальном GitHub SagerNet, скачивание Windows-архива, обязательная проверка SHA-256 и локальная установка с подтверждением. 
- Системный трей с переключателем, локальный очищенный JSON-отчёт и опциональная публикация агрегированной статистики в GitHub.
- Автоматическое определение базовых характеристик ПК при старте.

## Что именно проверяется

1. Быстрый режим проверяет доступность TCP-адреса и порта. Он не доказывает, что прокси/VPN работает.
2. Полный режим для поддерживаемых форматов запускает sing-box с отдельным локальным SOCKS5-входом и проверяет HTTPS-ответ через конкретную конфигурацию. Это реальный протокольный тест, а не TCP ping.
3. VLESS, VMess, Trojan, Shadowsocks, Hysteria2 и TUIC поддерживаются в распространённых вариантах. Нестандартные транспорты, плагины и некоторые специфические параметры могут быть отмечены как неподдерживаемые.
4. На Windows не создаётся TUN-интерфейс, не меняются системные маршруты и DNS. Проверка всё равно создаёт исходящее соединение к тестовому HTTPS-сайту через проверяемую конфигурацию.

**Важно:** протокольный тест использует сетевой трафик и может быть медленнее TCP-проверки. Для полной проверки нужен установленный официальный sing-box.

## Что ещё не включено

- Проверка всех нестандартных вариантов транспортов и плагинов: неизвестные параметры явно помечаются как неподдерживаемые.
- Автоматическое определение произвольных целевых сайтов для теста: сейчас используется фиксированный HTTPS endpoint.
- Проверка обновлений самого VPNDesk с подтверждением установки.
- Автозапуск вместе с Windows с отдельным подтверждением.
- Полноценная многозадачная очередь источников и независимые задачи; сейчас приложение допускает одну активную фоновую задачу.
- Восстановление базы через мастер интерфейса (резервные копии создаются).
- Полностью фоновый watcher папок: текущая проверка списка файлов вызывается таймером GUI.
- Географическая карта серверов. «Карта источников» — это карта происхождения данных.

## Запуск на Windows 10/11

1. Распакуй исходный архив в папку, доступную для записи.
2. Установи Python 3.11 или новее с python.org.
3. Запусти `run.bat` — скрипт создаст `.venv`, установит зависимости и запустит приложение.
4. Для сборки папки с EXE запусти `build.bat`. Результат появится в `dist\VPNDesk\VPNDesk.exe`.

Сборка требует доступа к PyPI при первом запуске. PySide6, keyring и psutil устанавливаются автоматически в виртуальное окружение.

## Данные и безопасность

По умолчанию данные находятся в `%LOCALAPPDATA%\VPNDesk\`:

- `vpndesk.db` — SQLite база и история;
- `settings.json` — настройки без GitHub-токена;
- `backups\` — резервные копии;
- `reports\latest-stats.json` — локальный очищенный отчёт.

GitHub-отчёт содержит только агрегированные счётчики и время. URI, адреса, порты и токены в отчёт не включаются. Токен хранится через системное хранилище учётных данных.

Экспортированные TXT могут содержать секретные URI. Храни их приватно.

## Автоматические тесты

Из папки проекта:

```bat
py -3 -m unittest discover -s tests -v
```

В этой аудит-сборке: **31 автоматический тест проходит** на Python 3.13 в Linux-среде. Они проверяют парсер, ZIP-импорт, миграцию SQLite, атомарный импорт, историю, мягкий рейтинг, распределение энергосберегающей квоты, ограниченную очередь и отмену с сохранением частичных результатов.

Qt GUI, PyInstaller EXE, системный трей, Windows shutdown и поведение на чистой Windows не могли быть исполнены в текущей среде: здесь нет PySide6/Windows runtime, а загрузка зависимостей из сети недоступна. Перед production-релизом нужен запуск `run.bat` и `build.bat` на Windows 10/11 и визуальная проверка.
