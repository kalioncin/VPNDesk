# История изменений VPNDesk

## 0.4.0-audit
- Добавлена прокрутка всех страниц интерфейса.
- Первый запуск предлагает базовую диагностику ПК и выбор лёгкого/среднего/интенсивного профиля.
- Добавлен предварительный тест URL-источников перед импортом.
- Таблицы поддерживают множественный выбор, выбор всех и массовое удаление источников.
- Добавлена реальная протокольная проверка через sing-box с HTTPS-запросом через локальный SOCKS5; системный TUN и маршруты не меняются.
- В каталоге показывается тип последней проверки.
- Производительность имеет резервное получение показателей памяти и диска, если psutil недоступен.

## 0.3.0-audit

- Добавлена история проверок конфигураций и источников.
- Добавлена мягкая оценка источников с учётом свежести, успешности, доли доступных записей и TCP-задержки.
- Одна конфигурация теперь может иметь несколько источников происхождения.
- Импорт выполняется атомарно.
- Добавлена ограниченная очередь TCP-проверок с паузой, отменой и сохранением частичных результатов.
- Добавлены управление источниками, карта происхождения, рейтинг и аналитика.
- Добавлены центр качества данных, экран производительности, самодиагностика и обслуживание.
- Добавлены энергосберегающий лимит, портативный режим, проверка характеристик устройства и опциональное автовыключение после финальной проверки.
- Добавлен менеджер загрузки официального sing-box с проверкой SHA-256.
- Усилены ограничения ZIP-импорта.
- Исправлен сценарий завершения приложения при отключённом системном трее.

## 0.2.0

- Начальный Windows MVP с SQLite, импортом, парсером URI, TCP-проверкой и GitHub-отчётами.
