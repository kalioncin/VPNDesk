# VPNDesk

**VPNDesk** — Windows-приложение для импорта, каталогизации, проверки и анализа VPN-конфигураций.

**Базовая версия:** 0.4.0-audit. Это расширенная аудит-сборка, а не подтверждённый production-релиз.

## Исходная версия 0.4.0-audit

Проект ориентирован на VLESS, VMess, Trojan, Shadowsocks, Hysteria2 и TUIC. В сборке есть PySide6 GUI на русском языке, SQLite-каталог, импорт TXT/JSON/YAML/CSV/CONF/LIST/ZIP, парсер, TCP-проверка, протокольная проверка через sing-box для поддерживаемых вариантов, очередь TCP-проверок, история и рейтинг источников, отчёты, резервное копирование, портативный режим и менеджер sing-box.

Фактическую реализацию функций следует проверять по исходному коду. **TCP-доступность не доказывает работоспособность VPN.** Отсутствующий компонент, неподдерживаемый транспорт или невыполненная проверка не должны отображаться как успех.

## Проверка исходного архива
- `python -m compileall -q .` — успешно.
- `python -m unittest discover -s tests -v` — 31 тест пройден.

Это проверки в текущей Linux-среде, не Windows GUI/EXE тестирование. Исходный аудит не подтвердил DPI, системный трей, выключение Windows и живой сетевой прогон sing-box. Некоторые нестандартные транспорты/плагины не поддерживаются; часть функций обновления, восстановления и многозадачности остаётся незавершённой.

## Запуск в Windows
Требуется Windows 10/11 и Python 3.11+:

```bat
run.bat
```

Сборка:

```bat
build.bat
```

Наличие скрипта не означает, что EXE собран и проверен.

## Тесты

```bash
python -m compileall -q .
python -m unittest discover -s tests -v
```
