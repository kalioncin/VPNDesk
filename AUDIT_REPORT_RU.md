# VPNDesk 0.4.0-audit — отчёт изменений и ограничений

## Исправления по отзывам

1. Все страницы приложения размещены в вертикально прокручиваемых областях.
2. Первый запуск предлагает базовую диагностику характеристик компьютера и выбор профиля: лёгкий, средний или интенсивный. Интенсивный профиль имеет аппаратные ограничения и не пытается намеренно зависать или перегружать Windows.
3. Таблицы конфигураций и источников поддерживают множественный выбор, кнопки «Выбрать все» и «Снять выбор». Для источников доступно массовое удаление с подтверждением.
4. Предпросмотр импорта URL позволяет включить предварительный тест источников. Тест выполняется в фоне с прогрессом; в импорт попадают только успешно прочитанные URL, а найденные конфигурации добавляются к каталогу.
5. Добавлена полная проверка через sing-box: для распространённых URI строится outbound, запускается отдельный временный процесс и выполняется HTTPS-запрос через локальный SOCKS5. TUN, системные маршруты и DNS не меняются.
6. В каталоге конфигураций отображается тип последней проверки: `tcp` или `sing-box`.
7. Экран производительности получает RAM/disk через резервные Windows API/стандартную библиотеку, если psutil недоступен.

## Полная проверка протокола

Преобразователь покрывает распространённые варианты VLESS, VMess, Trojan, Shadowsocks, Hysteria2 и TUIC. Распространённые WS/gRPC/HTTP Upgrade транспорты поддерживаются частично. Неизвестные транспорты и Shadowsocks plugins явно отклоняются, а не интерпретируются наугад.

Для каждого теста создаётся временный sing-box JSON, сначала запускается `sing-box check`, затем `sing-box run` с SOCKS5 listener на loopback. Через него проверяется HTTPS-ответ тестового endpoint. Временный процесс завершается после теста. Проверка создаёт сетевой трафик через конфигурацию и может быть медленнее TCP-проверки.

## Автоматические проверки

- `python -m compileall -q .` — успешно.
- `python -m unittest discover -s tests -v` — **31 тест пройден**.
- Проверены генераторы outbound для VLESS Reality/WS, VMess/WS, Trojan, Shadowsocks, Hysteria2 и TUIC; неподдерживаемый транспорт отклоняется.
- Проверены SQLite, импорт, парсер, ZIP-защита, история, рейтинг источников, энергосберегающая квота и отмена TCP-очереди.

## Что не удалось подтвердить здесь

В текущей среде нет PySide6 и Windows runtime. Поэтому не удалось визуально запустить Qt-интерфейс, проверить прокрутку на реальном DPI, собрать Windows EXE, проверить системный трей и выключение Windows. Также не выполнялся живой сетевой прогон с официальным sing-box против действующих серверов. Проверка генерации JSON-конфигураций прошла unit-тестами, но совместимость с установленной версией sing-box должна быть подтверждена на Windows.

Эта сборка — расширенная тестовая версия, а не подтверждённый production-релиз. Для окончательного выпуска необходим запуск `run.bat`, установка sing-box через раздел «Компоненты» и реальная проверка нескольких тестовых конфигураций на Windows 10/11.
