# VPNDesk 0.4.0-audit

Исходная аудит-сборка проекта VPNDesk.

## Состав
- Исходный код Python/PySide6 и SQLite.
- Импорт и парсер VPN-конфигураций VLESS, VMess, Trojan, Shadowsocks, Hysteria2 и TUIC.
- TCP-проверка и протокольная проверка через sing-box для поддерживаемых вариантов.
- История проверок, управление источниками, рейтинг, отчёты, резервное копирование и менеджер компонентов.
- Автоматические тесты и документация.

## Проверки
- `python -m compileall -q .` — успешно.
- `python -m unittest discover -s tests -v` — 31 тест пройден.

## Ограничения
Это аудит-сборка, не подтверждённый production-релиз. Windows GUI/EXE и живой сетевой прогон sing-box не были подтверждены в исходном аудите. Некоторые транспорты и функции остаются ограниченными. Подробности — `AUDIT_REPORT_RU.md`.
